HOW TO INSTALL · EVERY DEVICE

PC — Chrome / Edge / Firefox

  1. Show the bookmarks bar: Ctrl+Shift+B — same keys on a Chromebook.
  2. Right-click the bar → Add page… (Firefox: Bookmark This Page).
  3. Name it Securly JavaScript, paste the code into the URL box. Save.
  4. Click the bookmark on any page.

iPhone & iPad — Safari

  1. On any page: Share (square with up arrow) → Add Bookmark → Save.
  2. Book icon → tap the bookmark → Edit (or long-press → Edit).
  3. Erase the URL, paste the code, tap Done.
  4. Tap the bookmark on any page.

Android — Chrome

  1. Chrome on Android can't edit bookmark addresses — do the PC steps in the same Google account, enable sync on the phone, done.
  2. Or use Firefox: ⋮ → Bookmarks → long-press → Edit → paste code.
  3. Tap the bookmark on any page.

Every device — quick tips

  1. Click the bookmark itself — typing the code in the address bar just searches.
  2. Nothing opens? Allow pop-ups for that site, then click again.
  3. Launcher loads but a game stalls? Try the bookmark from a different page.

It updates itself. This page pulls bookmarklet.js from the CDN on every visit (@main = latest commit), so after you push new code the newest version is already waiting here. Install once — never touch the bookmark again.
