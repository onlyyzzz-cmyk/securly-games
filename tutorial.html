beginner tutorial

start playing in seconds

New here? Follow these quick steps to find a game, launch it, and keep your favorites close.

01 / FIND

Browse or search

Scroll through the game grid, or type a title into the search box at the top. The list filters as you type.

02 / PLAY

Choose a game

Click any game card to open it. Wait for the game to load, then use your keyboard, mouse, or touch controls.

03 / SAVE

Keep favorites

Use the star control on a game card to save it. Open favorites in the sidebar whenever you want to find it again.

04 / RETURN

Go back safely

Use the back button in the game view or your browser's back button to return to the game library.

Quick tip: Try the lucky button when you cannot decide what to play. It picks a game for you.
